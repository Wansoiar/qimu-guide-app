# 齐目导览 · Android App 产品需求文档

> **版本**: v2.1 | **日期**: 2026-07-25 | **状态**: 待评审
>
> 本文档描述 AI 智能导览系统 Android App「齐目导览」的完整产品设计。

---

## 1. 产品概述

### 1.1 定位

「齐目导览」Android App 是 AI 智能导览系统的 C 端载体，预装在投放手机中，无账户概念。游客在博物馆/景区现场自行完成取眼镜 → 连接眼镜 → 拍照/语音提问 → 听讲解 → 导出的完整体验。

### 1.2 核心功能

游客通过眼镜物理按键触发拍照或语音提问，App 实时同步展示对话内容，AI 讲解词通过眼镜耳机播报，并在 App 屏幕以文字呈现。游客可通过导出功能生成二维码扫码带走完整记录，或一键导出游览 Vlog。

### 1.3 无账户模型

- App 预装在投放手机中，无登录/注册
- 每次使用以单次会话（session）为唯一标识
- 会话 ID 在用户点击「开始使用」时由服务端生成
- 所有数据绑定到该会话 ID
- 结束使用后会话关闭，数据仅可通过导出获取

### 1.4 用户操作路径

```
打开 App → 挂牌页 → 选择场馆（默认定位）→ 「开始使用」
→ 扫描并连接眼镜 → 对话页 ← → 导出页
→ 「结束使用」→ 回到挂牌页
```

### 1.5 页面一览

| 页面 | 类型 | 准入条件 |
|------|------|---------|
| 挂牌页 | 首页 | 无 |
| 设备管理 | Tab | 已开始使用 |
| 对话 | Tab | 已连接眼镜 |
| 导出 | Tab | 已开始使用 |

---

## 2. 挂牌页

App 启动后默认进入。

| 元素 | 说明 |
|------|------|
| Logo + 名称 | 品牌展示 |
| 当前场馆 | 自动定位（GPS），可手动切换 |
| 「开始使用」按钮 | 创建会话，进入主界面 |
| 「结束使用」按钮 | 关闭会话 + 断开连接 + 回挂牌页 |

场馆默认通过手机 GPS 定位自动选择，用户可点击切换场馆列表。未选择场馆时「开始使用」不可点击。

---

## 3. 设备管理页

### 3.1 未连接

| 元素 | 说明 |
|------|------|
| 标题 | "设备管理" |
| 设备卡片 | 显示上次使用设备 + "未连接"标签 |
| 「扫描并连接眼镜」按钮 | 开始 BLE 扫描 |

### 3.2 已连接

| 字段 | 说明 |
|------|------|
| 设备名 | 连接时获取 |
| 设备 ID | 连接时获取 |
| 电量 | 实时上报 |
| 信号 | 实时 RSSI |
| 固件版本 | 连接时获取 |

### 3.3 连接流程

扫描（15s）→ 发现设备列表 → 选中 → 连接（10s）→ 已连接

---

## 4. 对话页

### 4.1 顶部

场馆名 + AI 状态（空闲 / 识别中 / 思考中 / 讲解中）

### 4.2 对话气泡

| 类型 | 触发 | 内容 |
|------|------|------|
| 用户拍照 | 按眼镜拍照键 | 照片 + 时间戳 |
| 用户语音 | 按麦克风键 | 转写文字 + 时间戳 |
| AI 讲解 | 服务端返回 | 流式文字 + 状态行 + 时间戳 |

### 4.3 多轮对话

- 同一会话内可连续提问，追问自动关联上下文
- 底部固定引导文案："通过眼镜操作提问，手机端仅供查看"
- 语音重播按钮：重播最近一次 AI 讲解

---

## 5. 导出页

### 5.1 导出内容

| 类型 | 导出方式 |
|------|---------|
| 对话记录 | 二维码 → 网页预览/下载 |
| 图片 | 二维码 → 网页预览/下载 |
| 音频 | 二维码 → 网页预览/下载 |
| 会话摘要 | 二维码 → 网页查看 |
| Vlog | App 本地合成，保存到相册 |

### 5.2 二维码导出

点击「生成二维码」→ 服务端生成导出链接 → 显示二维码 → 游客扫码打开网页预览/下载。有效期 30 分钟，可「再次生成」。

### 5.3 Vlog 导出

点击「导出 Vlog」→ App 本地将图片 + 音频 + 文字合成短视频 → 保存到相册 → 支持分享。合成时显示进度条。

---

## 6. 全局交互

| 约束 | 说明 |
|------|------|
| 结束使用 | 全局按钮 → 确认弹窗 → 关闭会话 + 断开连接 → 回挂牌页 |
| 眼镜断开 | 弹窗提示，数据保留可导出 |
| App 被杀重启 | 回挂牌页 |
| 新消息自动滚底 | 手动上滑查看历史时不滚 |
| 会话驻留 | 切换 Tab 再返回，对话内容保持 |

---

## 7. 边界 Case

| # | 场景 | 处理 |
|---|------|------|
| E-01 | 扫描超时 15s | 提示 + 重新扫描 |
| E-02 | 连接超时 10s | 提示 + 重试 |
| E-03 | 连接被拒 | 提示重启眼镜 |
| E-04 | 眼镜断开 | 弹窗提示 |
| E-05 | 低电量 < 10% | 黄色警告 |
| E-06 | 电量 ≤ 3% | 强制结束会话 |
| E-07 | 拍照识别失败 | 兜底提示 |
| E-08 | 网络异常 | 气泡标红 + 重试 |
| E-09 | 服务端限流 | 排队提示 |
| E-10 | 连续快速提问 | 忽略 + 提示等待 |
| E-11 | 语音 < 1s | 不上传 + 提示 |
