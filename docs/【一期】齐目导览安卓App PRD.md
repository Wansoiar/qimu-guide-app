## 1. 产品概述

### 1.1 定位

「齐目导览」Android App 是 AI 智能导览系统的 C 端载体，预装在投放手机中，无账户概念。每次使用以单次会话为唯一标识。

### 1.2 核心功能一句话

游客通过眼镜物理按键触发拍照或语音提问，App 实时同步展示对话内容，AI 讲解词通过眼镜耳机播报，并在 App 屏幕以文字呈现。

### 1.3 用户操作路径

```
管理员开机 → 打开 App → 挂牌页
→ 输入订单号或手机号 → 选择场馆 → 「开始使用」
→ 扫描并连接眼镜 → 进入对话页
→ 戴眼镜拍照/语音提问 → 耳机播放讲解
→ 「导出」Tab → 生成二维码 / 导出 Vlog
→ 「结束使用」→ 回到挂牌页
```

### 1.4 无账户模型

- App 预装，无登录/注册
- 每次使用以会话 ID 为唯一标识
- 会话 ID 在「开始使用」时由服务端生成
- 所有数据绑定到会话 ID
- 结束使用后会话关闭，数据仅可通过导出获取

### 1.5 页面一览

| 页面 | 类型 | 准入条件 |
|------|------|---------|
| 挂牌页 | 首页 | 无 |
| 设备管理 | Tab | 已开始使用 |
| 对话 | Tab | 已连接眼镜 |
| 导出 | Tab | 已开始使用（有会话数据） |

## 3. 挂牌页

App 启动后默认进入。

| 元素 | 说明 |
|------|------|
| Logo + 名称 | 品牌展示 |
| 输入框 | 订单号或手机号（待定） |
| 场馆选择 | 下拉列表，从服务端拉取 |
| 「开始使用」按钮 | 创建会话，进入主界面 |
| 「结束使用」按钮 | 关闭会话，断开眼镜，回到挂牌页 |

场馆从服务端拉取，用户手动选择，后续 AI 检索限定在该场馆知识库内。

## 4. 设备管理页

### 4.1 未连接状态

| 元素 | 说明 |
|------|------|
| 标题「设备管理」 | 固定文案 |
| 设备卡片 | 显示上次使用的设备 |
| 「扫描并连接眼镜」按钮 | 开始扫描 |

### 4.2 已连接状态

| 字段 | 说明 |
|------|------|
| 设备名 | 连接时获取 |
| 设备 ID | 连接时获取 |
| 电量 | 眼镜实时上报 |
| 信号 | 实时显示 |
| 固件版本 | 连接时获取 |

### 4.3 连接流程

扫描（30s 超时）→ 发现设备列表 → 选中 → 连接（10s 超时）→ 已连接

## 5. 对话页

| 区域 | 内容 |
|------|------|
| 顶部 | 场馆信息 + AI 状态标签 |
| 中部 | 对话气泡流 |
| 底部 | 操作提示 |

### 5.1 气泡类型

| 类型 | 触发 | 内容 |
|------|------|------|
| 拍照 | 按眼镜拍照键 | 照片 + 时间戳 |
| 语音 | 按麦克风键 | 转写文字 + 时间戳 |
| AI 讲解 | 服务端返回 | 流式文字 + 状态 |

多轮对话，追问自动关联上下文。一次会话 = 一次「开始使用」到「结束使用」。

---

## 6. 导出页

### 6.1 导出内容

| 类型 | 导出方式 |
|------|---------|
| 对话记录 | 二维码 → 网页 |
| 图片 | 二维码 → 网页 |
| 音频 | 二维码 → 网页 |
| 会话摘要 | 二维码 → 网页 |
| Vlog | 一键导出到本地 |

### 6.2 二维码导出

点击「生成二维码」→ 服务端生成链接 → 显示二维码 → 游客扫码打开网页查看/下载。有效期 30 分钟。

### 6.3 一键导出 Vlog

点击「导出 Vlog」→ 合成本次会话的短视频 → 保存到本地 → 支持分享。

### 6.4 页面状态

| 状态 | 显示 |
|------|------|
| 未生成二维码 | 生成按钮 + 说明 |
| 已生成 | 二维码 + 倒计时 + 再次生成 |
| Vlog 未导出 | 导出按钮 |
| Vlog 已导出 | 预览 + 分享 |

---

## 7. 全局交互约束

- 「结束使用」全局可用 → 确认弹窗 → 关闭会话、断开连接、回挂牌页
- 眼镜断开时弹窗提示，数据保留
- App 切后台对话不中断
- App 被杀死重启 → 回挂牌页
- 新消息自动滚底，手动上滑时不滚

## 8. 边界 Case 处理

| # | 场景 | 处理 |
|---|------|------|
| E-01 | 扫描超时 30s | 提示 + 重试 |
| E-02 | 连接超时 10s | 提示 + 重试 |
| E-03 | 连接被拒 | 提示重启眼镜 |
| E-04 | 眼镜断开 | 弹窗提示 |
| E-05 | 低电量 < 10% | 黄色警告 |
| E-06 | 电量 ≤ 3% | 强制结束会话 |
| E-07 | 拍照识别失败 | 兜底提示 |
| E-08 | 拍错场馆 | 提示 |
| E-09 | 网络异常 | 气泡标红 + 重试 |
| E-10 | 服务端限流 | 排队提示 |
| E-11 | 连续快速提问 | 忽略 + 提示 |
| E-12 | 语音 < 1s | 不上传 + 提示 |
