## 1. 产品概述

### 1.1 定位

「齐目导览」Android App 是 AI 智能导览系统的 C 端载体，预装在投放手机中，无账户概念。游客在博物馆/景区现场自行完成取眼镜 → 连接眼镜 → 拍照/语音提问 → 听讲解 → 导出的完整体验。

### 1.2 核心功能

游客通过**语音关键词**触发拍照（如说"拍照"、"拍这个"），或直接说话提问，App 实时同步展示对话内容。AI 讲解词通过眼镜耳机播报，并在 App 屏幕以文字呈现。每个 AI 讲解气泡都带有重新播放按钮。游客可通过导出页生成二维码扫码带走完整记录和 Vlog。

### 1.3 无账户模型

- App 预装在投放手机中，无登录/注册
- 每次使用以单次会话（session）为唯一标识
- 会话 ID 在用户点击「开始使用」时由服务端生成
- 所有数据（对话记录、图片、Vlog）绑定到该会话 ID
- 结束使用后会话关闭，数据仅可通过导出获取

### 1.4 用户操作路径

```
打开 App → 挂牌页（GPS 定位场馆）→ 「开始使用」
→ 扫描并连接眼镜 → 对话页
  ├─ 说"拍照"/"拍这个" → 眼镜拍照 → 照片回传
  ├─ 说话提问 → ASR 识别 → AI 回答 → 讲解播报
  └─ 每个 AI 气泡可重播
→ 导出页 → 生成二维码 → 扫码带走数据/Vlog
→ 「结束使用」→ 回到挂牌页
```

### 1.5 页面一览

| 页面 | 类型 | 准入条件 |
|------|------|---------|
| 挂牌页 | 首页 | 无 |
| 设备管理 | Tab 1 | 已开始使用 |
| 对话 | Tab 2 | 已连接眼镜 |
| 导出 | Tab 3 | 已开始使用 |

## 2. 挂牌页

App 启动后默认进入，作为每次使用的起点和终点。

### 2.1 核心元素

| 元素 | 说明 |
|------|------|
| Logo + 名称 | 品牌展示 |
| 当前场馆 | GPS 自动定位，显示场馆名 + 下拉切换按钮 |
| 「开始使用」按钮 | 深棕金色实心，创建会话，进入主界面 |
| 「结束使用」按钮 | 灰色，会话进行中可点击 → 确认弹窗 → 关闭会话、断开连接、回挂牌页 |

### 2.2 场馆选择

- App 启动后通过手机 GPS 定位获取当前位置
- 服务端返回附近场馆列表，自动选中最近场馆
- 用户可点击场馆名展开下拉列表手动切换
- 未选择场馆时「开始使用」按钮不可点击
- 场馆影响后续所有 AI 检索的知识库范围

### 2.3 结束使用流程

点击「结束使用」→ 弹窗确认 → 确认后调用服务端关闭会话 → 断开眼镜 BLE 连接 → 清空会话状态 → 回到挂牌页。

## 3. 设备管理页

### 3.1 未连接状态

| 元素 | 说明 |
|------|------|
| 页面标题「设备管理」 | 固定文案 |
| 设备信息卡 | 显示设备名 + "未连接"标签（灰色），上次使用设备 |
| 「扫描并连接眼镜」按钮 | 深棕金色实心，点击开始 BLE 扫描 |
| 提示文字 | "连接眼镜后可使用实时讲解功能" |

扫描期间按钮变为「取消扫描」。扫描超时（15s）提示"未发现设备" + 「重新扫描」按钮。

### 3.2 已连接状态

设备信息卡切换为高亮状态，展示实时数据：

| 字段 | 数据来源 |
|------|---------|
| 设备名 | 连接时获取 |
| 设备 ID | 连接时获取 |
| 电量百分比 | 眼镜实时上报，持续更新 |
| 信号强度（RSSI） | 实时显示 |
| 固件版本 | 连接时获取 |

### 3.3 连接流程

扫描（15s 超时）→ 发现设备列表（名称 + MAC + RSSI）→ 用户选中 → 发起连接（10s 超时）→ 连接成功 → 切换到已连接状态，解锁对话 Tab。

## 4. 对话页

### 4.1 页面结构

| 区域 | 内容 |
|------|------|
| 顶部 | 场馆名 + AI 状态标签（空闲 / 识别中 / 思考中 / 讲解中） |
| 中部 | 对话气泡流（自动滚动到底部，手动上滑时暂停自动滚） |
| 底部 | 固定引导文案："通过眼镜操作提问，手机端仅供查看" |

### 4.2 三种对话气泡

#### 4.2.1 用户拍照气泡

用户说出"拍照"、"拍这个"、"拍一张"等关键词时，触发眼镜拍照，照片实时回传显示。

| 属性 | 内容 |
|------|------|
| 触发方式 | 用户说话中包含拍照关键词 |
| 气泡内容 | 照片缩略图 + 时间戳 |
| 位置 | 靠右对齐 |
| 角标 | 📷 |

#### 4.2.2 用户语音气泡

用户说话提问时，语音经 ASR 转写为文字后展示。

| 属性 | 内容 |
|------|------|
| 触发方式 | 用户对着眼镜说话 |
| 气泡内容 | 语音转写文字 + 时间戳 |
| 位置 | 靠右对齐 |
| 角标 | 🎤 |
| 状态变化 | 收音中 → 转写中 → 展示转写文字 |

#### 4.2.3 AI 讲解气泡

| 属性 | 内容 |
|------|------|
| 触发方式 | 服务端完成 AI 讲解词生成 |
| 气泡内容 | AI 讲解文字（流式逐字展示）+ 分隔线 + 🔊 重新播放按钮 + 时间戳 |
| 位置 | 靠左对齐 |
| 角标 | 🤖 |
| 说明 | **每个 AI 讲解气泡底部都有独立的「🔊 重新播放」按钮**，点击重播该条讲解语音，不限次数 |

### 4.3 多轮对话

- 同一会话内可连续提问，对话流自然延续
- 追问自动关联上一轮展品上下文
- 拍照和语音可交替使用
- 一次会话 = 一次「开始使用」到「结束使用」的完整周期

## 5. 导出页

### 5.1 导出内容

| 类型 | 说明 | 导出方式 |
|------|------|---------|
| 对话记录 | 用户提问 + AI 讲解词完整文本 | 二维码 → 网页预览 / 下载 |
| 图片 | 游客拍的所有展品照片 | 二维码 → 网页预览 / 下载 |
| 音频 | AI 讲解语音文件 | 二维码 → 网页预览 / 下载 |
| 会话摘要 | 场馆、时间、时长等元信息 | 二维码 → 网页查看 |
| Vlog | 图片 + 音频 + 文字合成的游览短视频 | App 本地合成 → 二维码 → 网页下载 |

### 5.2 二维码导出

1. 点击「生成二维码」→ 调服务端创建导出链接 → 渲染为二维码
2. 二维码下方显示有效倒计时（默认 30 分钟）
3. 游客用自己的手机扫码 → 打开网页 → 预览/下载全部数据
4. 点击「再次生成」→ 旧链接失效，生成新二维码
5. 无会话数据时按钮灰显，提示"暂无导出数据"

### 5.3 Vlog 导出

1. 点击「导出 Vlog」→ App 本地将本次会话的图片、音频、文字合成为短视频
2. 合成过程中显示进度条
3. 合成完成后显示「生成二维码」→ 服务端生成 Vlog 下载链接 → 扫码后在网页下载
4. Vlog 文件在手机本地临时存储，不直接保存到相册

### 5.4 页面状态

| 状态 | 显示 |
|------|------|
| 初始 | 「生成二维码」按钮 + 「导出 Vlog」按钮 + 导出说明 |
| 已生成二维码 | 二维码 + 倒计时 + 「再次生成」按钮 |
| Vlog 合成中 | 进度条 |
| Vlog 完成 | "Vlog 已就绪" + 「生成下载二维码」按钮 |

## 6. 全局交互约束

| 约束 | 说明 |
|------|------|
| 结束使用 | 任意页面可通过全局按钮「结束使用」→ 确认弹窗 → 关闭会话、断开连接、回到挂牌页 |
| 会话驻留 | 同一会话内切换 Tab 再返回，对话内容保持不丢失 |
| 眼镜断开 | 眼镜断开时弹窗提示，当前会话数据保留在服务端，可通过导出获取 |
| App 退到后台 | 对话不中断；回前台时恢复 |
| App 被系统杀死重启 | 回到挂牌页，历史数据需通过导出获取 |
| 新消息自动滚底 | 用户手动上滑查看历史时不自动滚 |

## 7. 边界 Case 处理

| # | 场景 | 处理 |
|---|------|------|
| E-01 | 扫描超时（15s） | 提示"未发现设备" + 「重新扫描」按钮 |
| E-02 | 连接超时（10s） | 提示"连接超时，请靠近眼镜重试" + 重试 |
| E-03 | 连接被拒绝 | 提示"连接失败，请重启眼镜后再试" + 重试 |
| E-04 | 眼镜运行中断开 | 弹窗 🔌 眼镜连接已断开，数据已保留 + [重新连接] |
| E-05 | 眼镜低电量（< 10%） | 顶部黄色警告条 + 电量数字变红 |
| E-06 | 眼镜电量耗尽（≤ 3%） | 强制结束当前会话，提示"请归还" |
| E-07 | 拍照识别失败 | 兜底提示 + 引导"再拍一次" |
| E-08 | 拍到非本场馆内容 | 提示"这可能不是本场馆的展品" |
| E-09 | 网络异常（发送中） | 用户气泡角标变红感叹号 + 底部弹出 Toast |
| E-10 | 网络完全断开 | 全局网络错误条 |
| E-11 | 服务端限流 | 排队提示卡片（等待人数 + 预计时间） |
| E-12 | 连续快速提问（2s 内 > 3 次） | 忽略后续事件 + Toast 提示等待 |
| E-13 | 语音说话 < 1 秒 | 不上传 + 提示"说话时间太短" |
| E-14 | 定位失败 | 提示"无法获取当前位置" + 手动选择场馆 |
