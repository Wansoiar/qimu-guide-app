# 参观前使用教程

进入新的导览会话、首次打开对话页时，展示三步动图教程，替换原来只有文字和“开始参观”的弹窗。

1. AI 对话：播放 `res/raw/tutorial_ai_dialogue.mp4`，点击“下一步”。
2. 拍照提问：播放 `res/raw/tutorial_photo_question.mp4`，点击“下一步”。
3. 拍照记录：播放 `res/raw/tutorial_photo_record.mp4`，点击“开始参观”关闭教程。

第二、三步可以点“上一步”回看。使用 1080×1440、30 fps 的完整画面，以本地静音视频循环播放，避免低分辨率 GIF 放大及调色板压缩，随 APK 打包，离线循环播放；切换步骤从头播放，只播放当前页，进入后台暂停，退出时释放播放器。每一步有可供无障碍服务朗读的操作说明。

每次参观仅首次进入时展示，页面重建后保留当前步骤，完成后同一会话不再展示。开始下一次参观时从第一步重新开始。最后的“开始参观”与原有行为一致，只关闭教程，不自动开启麦克风或发起拍照。

素材沿用 2026-09-28 确认的 AI 对话 v3、拍照提问 v7、拍照记录 v6。两项拍照教程使用修正过镜腿连接、移除电源图标后的同一眼镜模型。

验证：

- `./gradlew -PqimuEnv=dev :app:assembleDebug :app:testDebugUnitTest :app:lintDebug :app:assembleDebugAndroidTest`
- 107 项单元测试通过。
- Android 15 / arm64 模拟器执行 `TourTutorialTest`，验证真实对话页入口、三项高清动画解码、播放推进、弹窗尺寸小于宿主页面、前后翻页、页面重建、完成退出、不自动收音、每次参观只展示一次及新参观重新展示。
- 实际三步截图留存于工作区 `outputs/tutorial-gifs-2026-09-28/app-integration/`。

本次验证使用开发环境构建和模拟器，没有进行真实眼镜 RTC、拍照或线上会话验收。

按用户要求，另以手机原有正式环境配置构建并覆盖安装到华为 JAD-AL00。安装前核对签名一致，使用 `adb install -r` 保留数据；安装后核对 APK SHA-256 与本地构建一致，并确认正常启动到 `MainActivity`。未创建或修改手机上的参观会话。

弹窗修正：居中显示圆角卡片，宽度与高度均小于宿主页面；背景导览页保留并压暗。标题、进度和前后翻页按钮保持原生文字，媒体按比例显示，不拉伸。首帧封面衔接播放器启动，加载失败可点按重试。高清素材从原始工程重新渲染，三维画布同步提高分辨率。

文案统一：前两步按钮均为“下一步”，第三步为“开始参观”；拍照提问动图内的提示为“点击「拍照提问」”，去掉 App 字样。
