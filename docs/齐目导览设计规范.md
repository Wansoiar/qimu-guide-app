# 齐目导览 · 设计规范（App 视觉）

> 版本：v1.0 · 2026-08-30
> 风格定位：**B · 徽派框景（自定义微调）** —— 米色宣纸底 + 檀棕 + 鎏金，适配寺庙 / 博物馆场景，追求「高级感 + 文化底蕴感」。
> 本文档由浏览器端设计配置器（`docs/design-preview/index.html`）多轮选型确定，是 Android 端落地（`res/values/colors.xml` / `styles.xml` / 各布局）的唯一依据。

---

## 1. 设计原则

1. **干净克制，拒绝细碎装饰**。不要：卡片右上角包边角标、标签前菱形小点、按钮渐变 + 内高光、无意义的渐变花边。装饰只保留三类：细金线、可选印章、宋体标题。
2. **描边 / 柔影错落**。同一屏内卡片不全部同质：常规主卡柔影无框，强调卡、提示卡细描边，气泡细描边，形成层次与节奏。
3. **暖色阴影**。所有投影统一使用暖棕灰 `rgba(47,31,13,…)`，禁止纯黑阴影。
4. **背景图是设计师给定素材**，App 端不提供换图选项；对话页背景图必须叠 20% 透明蒙层（这是 web 预览与 App 视觉差异的原因）。
5. **预览页结构与 App 实际一致**：固定顶栏（徽章 + 标题 + 状态）、底部三 Tab、对话页底部操作栏，均按线上真实布局还原。
6. **文化符号克制**。底蕴靠配色、宋体、金线、留白传达，不靠堆砌纹样。

## 2. 布局骨架（与 App 实际一致）

```
┌─────────────────────────────┐
│ 状态栏（9:41 · 系统）         │
│ 固定顶栏：40dp 徽章 + 齐目导览 + 状态点/文案 │
├─────────────────────────────┤
│ 内容区（三页切换）            │
│   · 对话页：会话卡 → 气泡流 → 展品卡 │
│   · 设备页：设备卡 → 指标块 → 导览卡 → 提示卡 │
│   · 导出页：大标题 → 照片卡 → 归还流程卡 → 提示卡 │
├─────────────────────────────┤
│ 底部导航：设备 / 对话 / 导出（三 Tab）│
│ 对话页额外：底部操作栏（状态行 + 双按钮）│
└─────────────────────────────┘
```

- 顶部固定：**40dp 圆形金底徽章** + 品牌标题「齐目导览」+ 状态点 / 文案（「设备在线」/「等待连接」）。
- 底部导航：`设备 / 对话 / 导出` 三 Tab，默认细线分隔。
- 对话页底部操作栏：状态行 + 「拍照提问」「开始对话」双按钮。

## 4. 字体与字阶

- **标题字体（宋体）**：`Noto Serif SC`，回退 `Songti SC` / `STSong`。
- **正文字体（黑体）**：`Noto Sans SC`，回退 `PingFang SC` / `Microsoft YaHei`。
- 标题字重统一 `700`；正文 `400`。

| 字级 | 字号 | 字重 | 字体 | 用途 |
|---|---|---|---|---|
| 顶部品牌标题 | 18 | 700 | 宋 | 顶栏「齐目导览」，字距 0.1em |
| 页面大标题 | 24 | 700 | 宋 | 如「导出照片」，字距 0.06em |
| 区块标题 | 15 | 700 | 宋 | 卡片标题：展品名、会话标题等 |
| 指标数值 | 18 | 700 | 宋 | 指标块数值：86%、12、01:42 |
| 正文 | 14 | 400 | 黑 | 气泡正文、卡片正文，行高 1.75 |
| 说明 | 13 | 400 | 黑 | 卡片辅助说明、归还流程步骤、使用提示 |
| 发言人标签 | 12 | 700 | 黑 | 气泡内「我」「齐目 AI」，鎏金色，字距 0.1em |
| 区块小标签 | 12 | 400 | 黑 | 卡片 kicker（如「使用提示」），字距 0.16em |
| 时间戳 | 11 | 400 | 黑 | 气泡时间，弱色 |
| 迷你标签 | 12 | 400 | 黑 | 刷新按钮、状态行 |
| Tab 文字 | 11–12 | 400/700 | 黑 | 底部导航，选中 700 鎏金 |

## 6. 间距规范

- 页面内容左右留白：**20dp**。
- 卡片内边距：**16dp**。

- 对话页内容纵向元素间距：13dp。
- 气泡内边距：**12dp 四边均匀**。

## 9. 组件规范

### 9.1 固定顶栏
- 底 `#F7F2E7`，底部 1dp 细线 `#E3D9C9`。
- 徽章：40dp 圆形，底 `#E9DAC3`，1dp `#D9BF98` 描边，内环高光（见 §7）。
- 标题「齐目导览」：18/700 宋体，字距 0.1em。
- 状态：7dp 圆点 + 11dp 文案（在线 `#5F7D55` / 等待连接弱灰 `#BDB3A5`），圆点带 3dp 同色 16% 光圈。
- 方案（备选）：檀棕匾额 / 深褐匾额（配置器可切换，当前选定：浅色宣纸）。

### 9.2 页面大标题（如「导出照片」）
- 24/700 宋体，字距 0.06em。
- **下划金线（当前选定）**：左对齐，宽 104dp、高 2dp，渐变 `#C9973B → 透明`。
- 备选：纯文字 / 印章点缀（左上角 26dp 印章红方块白字）/ 左侧金条（4dp 竖向渐变金条）。

### 9.3 卡片体系（错落组合，当前选定：主卡柔影 · 强调描边）
- **主卡（常规信息卡）**：米白 `#FFFEF9`，**无边框**，主柔影，圆角 12，内边距 16。
- **强调卡**（「下次导览场馆」「归还流程」）：米色 `#F2E9D9`，**1dp `#D8CCBC` 细描边**，轻影。
- **提示卡**（「使用提示」）：同强调卡，细描边。
- 备选组合：主卡描边·强调柔影 / 全部细描边 / 全部柔影无框。

### 9.4 指标块（电量、固件、待导出等）
- 底 `#F1EADA`，圆角 10，无边框，等分排布（flex:1，间距 8dp）。
- **左侧金线（当前选定）**：2dp 竖向渐变（透明→`#C9973B`→透明），位于块左缘垂直 26%–74% 段。
- 数值 18/700 宋体；标签 11dp `#9A8872`，字距 0.12em。
- 备选：纯色柔块 / 细描边块 / 顶部金线。

### 9.5 图标块
- 48dp（会话卡内 42dp），渐变 `#E9DAC3 → #DFC9A4`，1dp `#D9BF98` 描边，内顶高光。
- 图标字符 19–21dp，檀棕 `#6B4928`。

### 9.6 会话卡（对话页顶部）
- 结构：图标块 + 标题「齐目 AI 导览」+ 副文案 + 右侧状态胶囊。
- 状态胶囊「对话中」：鎏金文字 12dp，底 `rgba(168,112,30,.08)`，1dp `rgba(168,112,30,.28)` 描边，全圆角，横向内边距 11dp。

### 9.7 对话框（气泡）——无头像
- **AI 气泡**：横向 **100% 全宽**。
- **用户气泡**：**右对齐**，宽度 `fit-content`（内容横向撑开），**上限 86%**。
- 当前选定「宣纸描边」：AI 底 `#FAF6EC`，用户底 `#F2E9D9`，1dp `#D8CCBC` 细描边，圆角 12，内边距 12dp 四边均匀。
- 发言人标签：12/700 鎏金 `#A8701E`，字距 0.1em，下间距 5dp；**用户气泡内标签同样左对齐**。
- 正文 14/400，行高 1.75；时间戳 11dp `#9A8872`，上间距 6dp，**统一左对齐**。
- 备选：白底描边 / 柔影无框 / 描金细边 / 墨线工笔。

### 9.8 按钮（全部平底，无渐变、无内高光）
| 按钮 | 底 | 描边 | 文字 | 高度 |
|---|---|---|---|---|
| 主按钮（开始导览 / 结束游览） | 实心檀棕 `#6B4928` | 1dp 金线 `#D9BF98` | `#F4E9D2` | 48dp |

| 软按钮（开始对话） | 米色 `#F2E9D9` | 1dp 金线 `#D9BF98` | 深褐 `#52351D` | 48dp |
| 迷你按钮（刷新） | 米白 `#FFFEF9` | 1dp 细线 `#D8CCBC` | 文字次 `#7A6248`，hover 鎏金 | 自动 |

- 圆角 12（迷你 10），字距 0.08em，柔影（§7 轻影）。
- 主按钮备选：深褐描金 / 鎏金渐变 / 描边文字（配置器可切换，当前选定：实心檀棕）。

### 9.9 底部导航
- 底 `#FCFAF4`，顶部 1dp 细线 `#D8CCBC`。
- 选中：鎏金 `#A8701E`、字重 700、图标上浮 1dp；未选中：`#9A8872`。
- 备选：无分隔线 / 金线分隔（当前选定：细线分隔）。

### 9.10 展品缩略图（「已识别展品」卡）
- 66dp，深褐渐变 `#7C5A34 → #4A3520`，1dp 深色描边。
- 居中宋体「鼎」字水印 26dp，米白 90%，用作照片占位；正式照片加载后替换为实拍图。

### 9.11 状态行 / 状态点

## 12. 明确不要的（历史否决项）

- ❌ 卡片右上角包边 / 角标装饰。
- ❌ 标签前菱形 / 小图标点缀。
- ❌ 按钮渐变 + 内高光（「太土」「没质感」）。
- ❌ 指标块渐变花边作为唯一方案（改为可选项，最终选左侧金线）。
- ❌ 气泡头像（已移除，改为左侧全宽 / 右侧内容撑开）。
- ❌ 背景图切换选项（设计师给定素材）。
- ❌ 纯黑阴影、非暖色投影。
